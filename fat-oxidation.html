導讀：這一章在講什麼？

一句話：餓了的時候，把存著的脂肪拿出來、送進粒線體、燒成能量（ATP）。

「氧化」是什麼？＝拿走氫（電子）。β-氧化去氫產生 FADH₂、NADH，再到電子傳遞鏈換成 ATP。
狹義的「脂肪酸氧化」只指粒線體裡的 β-氧化（卡 3）；這一章是從脂肪存著到變成 ATP 的整趟路，所以前後還有其他圖卡。反方向「吃飽了把養分做成脂肪」是下一章「脂肪酸合成」。

看詳細版：每一步的酵素與輔酶

第 1 站　小腸：消化吸收

原料 → 產物TG → 2-單酸甘油 ＋ 2 脂肪酸
乳化膽鹽（兩性分子：一頭親水、一頭親油）→ 大油滴變小油滴 → 表面積增加
水解胰脂解酶（需 colipase）切開 TG 第 1、3 位的酯鍵
吸收膽鹽包成微膠粒 → 送到小腸細胞；膽鹽在迴腸回收
之後細胞內重組 TG → 包進乳糜微粒
進淋巴乳糜微粒太大，進不了微血管 → 絨毛中央的乳糜管（淋巴管）
之後怎麼進血液、怎麼到組織 → 看下一張卡
例外短、中鏈脂肪酸 → 門靜脈 → 肝
考點膽鹽 ＝ 膽酸 ＋ taurine 或 glycine（牛磺膽酸鈉、甘胺膽酸鈉）→ 幫脂肪酸吸收 第 5、7 題
colipase把胰脂解酶固定在膽鹽包住的油滴表面，才切得到 TG
進細胞怎麼做到微膠粒游到細胞表面 → 脂肪酸、2-單酸甘油離開微膠粒，穿過細胞膜（擴散＋膜上運輸蛋白）
膽鹽去哪留在腸腔 → 迴腸回收 → 回肝再用（腸肝循環）
出細胞TG ＋ apoB-48 包成乳糜微粒 → 胞吐送出

淋巴 → 血液 → 組織

路線乳糜管 → 腸淋巴管 → 乳糜池（腹部）→ 胸管（沿脊椎往上）→ 左鎖骨下靜脈與左頸內靜脈交會處
怎麼進血液不是擴散：胸管開口直接接在靜脈上，淋巴整股流進靜脈血
接口有瓣膜，防止血液倒流進淋巴
推動力淋巴沒有心臟推 → 靠骨骼肌收縮擠壓、呼吸時胸腔壓力變化、淋巴管壁收縮；瓣膜讓它只能往前
到組織肌肉、脂肪組織微血管內壁有脂蛋白脂解酶（LPL）；乳糜微粒上的 apoC-II 啟動它
切開TG → 脂肪酸 ＋ 甘油；脂肪酸穿出管壁進細胞，甘油隨血液到肝
進細胞後肌肉 → β-氧化產能；脂肪細胞 → 重組 TG 存起來
誰的 LPL 多吃飽：脂肪組織（胰島素增加）；飢餓：肌肉
剩下的乳糜微粒變小 → 乳糜微粒殘體 → 肝臟回收

第 2 站　脂肪組織：儲存與釋出

HSL 是什麼脂肪細胞裡的一種酵素，像一把剪刀；全名「激素敏感性脂解酶」＝聽激素指揮、剪脂肪的酵素
它剪什麼TG → 甘油 ＋ 3 個脂肪酸；TG 太大、不溶於水，要剪開才能離開脂肪細胞
打開／關掉打開＝剪刀開始剪（餓了、運動、緊張）；關掉＝剪刀停工（吃飽了），脂肪留著不動用
吃飽微血管壁的 LPL 切開乳糜微粒的 TG → 脂肪酸進脂肪細胞 → 重組 TG 存起來
餓了激素敏感性脂解酶（HSL）：TG → 甘油 ＋ 3 脂肪酸
打開 HSL昇糖素、腎上腺素、ACTH（需要能量）
關掉 HSL胰島素（吃飽了） 第 23 題
打開怎麼做到昇糖素、腎上腺素 → cAMP ↑ → 蛋白激酶 A 把 HSL 磷酸化 → 活化
關掉怎麼做到胰島素活化磷酸二酯酶 → cAMP ↓ → HSL 不被活化
切的順序ATGL 先切第 1 刀 → HSL → 單酸甘油脂解酶（考試答 HSL）
存的骨架脂肪細胞缺甘油激酶 → 甘油-3-磷酸要由葡萄糖來 → 吃飽才存得進去
全名荷爾蒙敏感性三酸甘油酯脂解酶（hormone-sensitive triacylglycerol lipase）
打開的激素（完整）腎上腺素、正腎上腺素、ACTH、TSH、昇糖素、生長激素、甲狀腺素
對抗只有胰島素 → 脂解 ↓、脂肪合成 ↑、血中游離脂肪酸 ↓
比喻激素＝門外老闆按電鈴（受體）；cAMP＝廣播；蛋白激酶 A＝拿印章的工頭；P＝章；HSL＝剪刀；胰島素＝關廣播（磷酸二酯酶）＋擦章（蛋白質磷酸酶）
同一個印章也管醣類蓋章 → 肝糖磷解酶開（分解肝糖）、肝糖合成酶關；胰島素讓三個一起反過來
動畫：HSL 怎麼被打開、怎麼被關掉

第 3 站　血液：運送

脂肪酸搭白蛋白（albumin） 第 4 題
甘油溶於水 → 肝 → 甘油-3-磷酸 → 二羥丙酮磷酸 → 甘油醛-3-磷酸 → 糖解或糖質新生 第 10 題
為什麼送肝脂肪細胞缺甘油激酶，肝臟才有
對比脂肪酸不論長短都走 β-氧化，不會變成甘油醛-3-磷酸
白蛋白怎麼載油性尾巴塞進白蛋白的口袋（非共價），一個可載好幾個
進細胞到組織放開 → 經細胞膜運輸蛋白進細胞

第 4 站　細胞：進粒線體

活化細胞質：脂肪酸 ＋ CoA → 脂肪醯輔酶 A（耗 ATP）
進粒線體靠肉鹼穿過內膜（見下一節）
切段β-氧化 → 乙醯輔酶 A
活化地點粒線體外膜（面向細胞質）；ATP → AMP ＋ PPi，等於花 2 個 ATP
例外短、中鏈脂肪酸不用肉鹼，直接進粒線體

第 5 站　粒線體：產能

路線乙醯輔酶 A → TCA 循環 → NADH、FADH₂ → 電子傳遞鏈 → ATP
交叉路口丙酮酸、乙醯輔酶 A 串聯三大營養素 第 26 題
單行道丙酮酸 → 乙醯輔酶 A 不可逆 → 脂肪酸不能變葡萄糖
能量16 碳棕櫚酸完全氧化 ≈ 106 ATP（舊課本 129）

另一個出口　肝臟：酮體

時機長期飢餓：乙醯輔酶 A 過多，草醯乙酸被拿去做糖
結果肝臟做成酮體 → 送大腦、肌肉當燃料 第 22 題
酮體有哪些乙醯乙酸、β-羥丁酸、丙酮（由 2 個乙醯輔酶 A 接成）
大腦脂肪酸（搭白蛋白）過不了血腦障壁 → 平時用葡萄糖，長期飢餓用酮體 第 21 題
怎麼用酮體肌肉、大腦把酮體變回乙醯輔酶 A → TCA → ATP
肝臟自己不用酮體（缺 β-酮醯基輔酶 A 轉移酶），只負責做
怎麼做2 乙醯輔酶 A → 乙醯乙醯輔酶 A → HMG-CoA（HMG-CoA 合成酶，關鍵酶）→ 乙醯乙酸 → β-羥丁酸；乙醯乙酸自行脫羧 → 丙酮（呼吸排出）
怎麼送溶於水，不用白蛋白；靠運輸蛋白進大腦
吃夠醣類可防酮酸中毒① 胰島素 ↑ → 乙醯輔酶 A 羧化酶 → malonyl-CoA ↑ → 抑制 CAT I → β-氧化 ↓；② 醣類 → 丙酮酸 → 草醯乙酸夠 → 乙醯輔酶 A 順利進 TCA，不堆積去做酮體

延伸：題目沒考，但課本有

這份 26 題沒有出現，但生化課本會教、國考可能會考的 3 種情況。

延伸 1　不飽和脂肪酸的 β-氧化

問題天然雙鍵是順式（cis），位置也不對，β-氧化的酵素認不得
例：油酸 18:1 Δ9先照常轉 3 圈（切掉 6 碳）→ 剩 12 碳，雙鍵落在 cis-Δ3
解法烯醯輔酶 A 異構酶：cis-Δ3 → trans-Δ2，剛好是 β-氧化第 ① 步的產物
結果跳過第 ① 步 → 這一圈少 1 個 FADH₂（少 1.5 ATP）
多元不飽和雙鍵在偶數位置（如亞麻油酸 Δ12）→ 另外要 2,4-二烯醯輔酶 A 還原酶，消耗 NADPH
記法雙鍵越多 → 產生的 ATP 越少一點

延伸 2　極長鏈脂肪酸：先在過氧化體切短

誰極長鏈脂肪酸（22 碳以上），粒線體處理不了
地點過氧化體（peroxisome），不靠肉鹼進入
第 ① 步不同醯基輔酶 A 氧化酶把電子直接交給 O₂ → 產生 H₂O₂（由過氧化氫酶分解）→ 不產生 ATP
其他步驟加水、去氫、硫解，和粒線體相同
切到多短約 8 碳 → 交給肉鹼 → 進粒線體繼續氧化
疾病過氧化體缺陷 → 極長鏈脂肪酸堆積，傷害神經（例：腎上腺腦白質失養症，電影《羅倫佐的油》）

延伸 3　α-氧化與 ω-氧化

α-氧化：誰植烷酸（phytanic acid）：在第 3、7、11、15 號碳有甲基分支
為什麼卡住β 碳（C3）上有甲基 → 第 ③ 步沒辦法變成酮基 → β-氧化做不下去
α-氧化怎麼做在過氧化體從羧基端只切掉 1 個碳（變 CO₂）→ 降植烷酸，甲基移到 α 碳 → 可以 β-氧化了
來源葉綠素的植醇 → 牛羊（反芻動物）的乳製品、脂肪，部分魚類
Refsum 病缺 α-氧化酵素 → 植烷酸堆積 → 周邊神經病變、視網膜色素病變；飲食限制乳製品與牛羊脂肪
ω-氧化在內質網從甲基端（ω 碳）氧化 → 兩端都是羧基的二羧酸；平常很少，β-氧化有缺陷時增加

附錄：第 34–39 題

原卷沒有標答案，第 27–33 題不在檔案中；以下為參考解答，請對照老師答案。

34.（題幹缺漏）剩下的選項「合成 PC 需要 SAM 提供甲基」本身正確：PE 加上 3 個甲基 → PC，甲基來自 SAM。

35. 答 C：Δ15 desaturase。亞麻油酸 18:2 Δ9,12 與次亞麻油酸 18:3 Δ9,12,15 只差第 15 碳的雙鍵；elongase 是延長碳鏈，不是加雙鍵。

36. 答 D：ethanolamine。腦磷脂（PE）的頭是乙醇胺；choline 屬卵磷脂，inositol 屬磷脂醯肌醇。

37. 答 C：lysine。色胺酸 → 血清素；麩胺酸本身是神經傳導物質，也能做成 GABA；酪胺酸 → 多巴胺、正腎上腺素、腎上腺素。

38. 答 C：合成 phosphatidylcholine 與 creatine 都需要 SAM 提供甲基。苯酮尿症是苯丙胺酸羥化酶缺陷；甲硫胺酸是必需胺基酸，由同半胱胺酸回收時反而需要甲基。

39. 答 B：甲硫胺酸合成酶把 5-甲基四氫葉酸的甲基交給同半胱胺酸，需要 B12。葉酸輔酶帶的是多個麩胺酸（不是麩醯胺酸）；同半胱胺酸升高是 B2、葉酸、B12「缺乏」造成。
